# Verifiable Time-lock Puzzles (VTLP) — Experiments

Welcome! 👋 This repository contains the **experimental code and benchmarks** for our paper:

> **"Check-Before-you-Solve": Verifiable Time-lock Puzzles**
> Jiajun Xin, Dimitrios Papadopoulos
> [https://eprint.iacr.org/2025/225.pdf](https://eprint.iacr.org/2025/225.pdf)

## About

This repo provides a **reproducible implementation** of the protocols and performance evaluations presented in our paper. Our work introduces **Verifiable Time-lock Puzzles (VTLPs)** — a new cryptographic primitive that allows anyone to *verify* the properties of a time-locked solution **before** investing computational resources to solve it, e.g., the time-locked solution is a valid signature. 
If you are interested in **time-lock puzzles, SNARKs, (RSA) signatures inside SNARKs, or decentralized applications**, you may find our code and benchmarks especially relevant! 

- 🕒 **Efficient verifiable time-lock puzzles for arbitrary NP relations**
- 🔑 **Efficient RSA signatures inside SNARK**
- ⚡ **Novel SNARK-offloading techniques for modular exponentiations**
- 📊 **Comprehensive performance evaluation and reproducibility**
